📘 Hammurabi Game
A modernised C# WinForms recreation of the classic Hammurabi resource‑management game — originally developed as a university project while learning procedural programming.

🏛️ About the Hammurabi Game
The Hammurabi game (also known as Hamurabi, Hammurapi, or The Sumer Game) is one of the earliest examples of a computer strategy simulation. It first appeared in the late 1960s and early 1970s on mainframe systems such as the DEC PDP‑8 and PDP‑10.

The gameplay is simple yet surprisingly deep:

You are Hammurabi, ruler of ancient Sumer.

Each year, you make decisions about how to allocate resources:

how many acres of land to buy or sell,

how much grain to feed your people,

how much grain to plant for next year’s harvest.

Random events — plagues, crop yields, rat infestations — influence your success.

Your goal is to keep your population alive and grow your kingdom.

Despite its simplicity, Hammurabi is historically significant. It taught early programmers about input handling, branching logic, randomness, and simulation design, and it remains a classic example of procedural programming.

🎓 About This Project
This version of Hammurabi was originally created as part of a university assignment while learning procedural programming in C#. The objectives were to:

implement the classic Hammurabi ruleset,

build a simple UI using Windows Forms,

practise control flow, functions, and basic state management,

understand how to structure a small simulation game.

Years later, the project has been revived, repaired, and modernised — fixing long‑standing build issues, cleaning up the WinForms designer structure, and restoring the game to a fully working state.

🖥️ Features
Classic Hammurabi gameplay loop

WinForms UI with numeric inputs and charts

Year‑by‑year simulation

Grain, land, and population management

Basic statistics visualisation
